# 341 农业知识综合三 · 考研学习站

面向江西农业大学 27 考研考生的 **341 农业知识综合三** 静态学习网站。科目构成：C语言程序设计 / 农业机械与装备 / 数据库技术与应用（各 50 分）。

姊妹站点：[815 农业推广学学习站](https://karrystar.github.io/815-agri-extension/) · [站点导航主页](https://karrystar.github.io/)

## 功能

- **科目主页**：三科目考情、分值构成与备考建议
- **章节学习**：三科目 17 章考点卡片（考频星级、助记、真题回顾）
- **机械图集**：农业机械考点配套示意图与动画演示（图片懒加载 + 视频）
- **名词解释**：翻卡背诵，支持科目筛选与已背标记
- **历年真题**：2020–2022 真题还原，按年份/题型/科目筛选，自动关联考点
- **自测练习**：选择/判断/填空/简答，即做即判带解析，进度本地保存
- 双端适配；图表 CDN 失效时自动降级为静态可视化

## 安装为应用（PWA）与多设备同步

- **安装**：本站作为「考研学习站」应用的一部分提供。打开导航主页 https://karrystar.github.io/ ，用 Chrome / Edge（安卓/电脑）菜单选择"安装应用"或"添加到主屏幕"，即可获得一个独立应用，应用内可进入 815 与 341 两个学习站，并支持**离线使用**（离线缓存由根站 Service Worker 统一覆盖，机械图集与视频首次在线观看后即可离线回看）。
- **多设备同步**：页面顶栏的 ↻ 按钮打开同步设置，支持 **WebDAV**（坚果云应用密码等）与 **OneDrive**（需自建 Azure SPA 应用，见设置页说明）。
- **同步方式**：按题目/名词/章节粒度合并（后写者胜出）；云端按站分文件备份，**同步配置在 815 / 341 之间互通**。
- 数据与凭据均为**明文**存储，未做加密，请勿在共用设备上保存密码。
