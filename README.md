# 341 农业知识综合三 · 考研学习站

面向江西农业大学 27 考研考生的 **341 农业知识综合三** 静态学习网站。科目构成：C语言程序设计 / 农业机械与装备 / 数据库技术与应用（各 50 分）。

姊妹站点：[815 农业推广学学习站](https://karrystar.github.io/815-agri-extension/) · [站点导航主页](https://karrystar.github.io/)

## 功能

- **科目主页**：三科目考情、分值构成与备考建议
- **章节学习**：三科目 17 章考点卡片（考频星级、助记、真题回顾）
- **机械图集**：农业机械考点配套示意图与动画演示（图片懒加载 + 视频）
- **名词解释**：翻卡背诵，支持科目筛选与已背标记
- **历年真题**：2020–2022 真题还原，按年份/题型/科目筛选，自动关联考点
- **自测练习**：选择/判断/填空/简答，即做即判带解析，进度本地保存
- 双端适配；图表 CDN 失效时自动降级为静态可视化

## 目录结构

```
├── index.html          # 入口
├── css/style.css       # 样式
├── js/app.js           # 路由与交互
├── data/               # 数据（window 注入，改数据无需动代码）
│   ├── clang.js        # C语言章节考点
│   ├── agmech.js       # 农机章节考点
│   ├── db.js           # 数据库章节考点
│   ├── exams.js        # 历年真题
│   ├── quiz.js         # 自测题库
│   ├── terms.js        # 名词解释
│   └── media.js        # 机械素材索引（考点id → 图片/视频）
└── assets/             # 机械示意图（ai图/原书配图）与演示视频
```

## 本地预览

```bash
# 浏览器打开 http://localhost:8000
```
